# Belajar Grid

This project is designed to help you learn and practice using CSS Grid Layout. It includes a simple HTML structure with a grid layout that contains empty boxes for experimentation.

## Project Structure

- `index.html`: Contains the basic HTML structure and sets up the grid layout with empty boxes.
- `styles.css`: Contains the CSS styles for the grid layout, defining the grid container properties and styles for the empty boxes.
- `README.md`: Documentation for the project, explaining how to use the grid layout and additional instructions for learning.

## How to Use

1. Open `index.html` in your web browser to view the grid layout.
2. Modify the `styles.css` file to change the appearance of the grid and the empty boxes.
3. Experiment with adding content to the grid items in `index.html` to see how the layout responds.

## Additional Instructions

Feel free to explore different grid configurations by adjusting the `grid-template-columns`, `grid-gap`, and other CSS properties in `styles.css`. This will help you understand how CSS Grid works and how to create responsive layouts.
